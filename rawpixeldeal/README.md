# RawPixelDeal Module - 医学图像预处理

本模块主要负责医学图像（如 CT, X-ray）的底层像素处理，利用 OpenCV 提供高性能的图像增强、去噪及重采样功能。

## 1. 预处理方法与顺序说明

在医学图像处理流程中，算子的执行顺序对最终质量至关重要。推荐的标准流水线顺序如下：

1.  **HU 值校正 (HU Convert)**：
    -   **逻辑**：首先将硬件采集的裸像素（Stored Value）通过 `Slope` 和 `Intercept` 转换为亨氏单位（Hounsfield Unit）。
    -   **原因**：这是物理意义的归一化，后续的去噪和增强算子通常基于具有物理意义的 HU 值进行参数设置。
2.  **图像去噪 (Denoising)**：
    -   **方法**：包括高斯滤波、中值滤波、双边滤波或频域 FFT 去噪。
    -   **逻辑**：在进行对比度增强前去除噪声，防止由于对比度提升导致噪声被同步放大。
3.  **重采样 (Resampling)**：
    -   **逻辑**：根据临床需求调整图像尺寸或空间分辨率。
4.  **对比度增强与归一化 (Enhancement & Normalization)**：
    -   **方法**：全局直方图均衡化、CLAHE（自适应直方图均衡）、对比度拉伸。
    -   **逻辑**：最后一步将高动态范围的医学数据映射到 8-bit 可视化区间，供屏幕显示。

## 2. 预处理总结及效果评估

| 预处理方法 | 核心原理 | 预期达到的效果 |
| :--- | :--- | :--- |
| **HU校正** | 物理映射 (SV -> HU) | 实现图像标准化，使不同设备采集的数据具有临床对比性。 |
| **双边去噪** | 空间与值域联合滤波 | **CT首选：** 在滤除背景噪声的同时，精准保留骨骼与器官的边缘轮廓，不产生模糊感。 |
| **频域FFT去噪** | 傅里叶变换滤波 | 有效消除成像过程中的周期性干扰，如采集电路产生的条纹噪声或环形伪影。 |
| **重采样** | 插值算法 | 统一图像分辨率，消除因物理传感器像素间距差异导致的几何变形。 |
| **CLAHE 增强** | 局部自适应直方图增强 | 显著提升软组织等低对比度区域的细节可见度，抑制全局均衡化带来的伪影。 |
| **对比度拉伸** | 线性区间映射 | 充分利用 0-255 灰度空间，使图像整体视觉效果更加明亮清晰。 |

## 3. 最终结论

通过本模块提供的可组合式预处理管线，能够有效地将原始含噪、低对比度的裸数据转化为符合临床诊断标准的影像。

-   **质量提升**：显著降低信噪比，提升关键解剖结构的识别度。
-   **灵活性**：通过 JNI 接口支持算子链的自由组合与参数微调，适应 X-ray 和 CT 等多种成像场景。
-   **性能保障**：核心算法由 C++ 与 OpenCV 实现，确保了移动端实时处理的响应速度。

## 4. 调用接口说明

### JNI 接口
```kotlin
RawPixelDealJni.processMedicalCT(
    rawBuffer, width, height, bitDepth, bigEndian, isUint16, ops, params, outInfo
)
```

### Kotlin 门面
使用 `MedicalCTPreprocess.process(...)` 方法，通过传入 `PreprocessStep` 列表即可轻松构建处理链。
