一、骨皮质、骨小梁标准密度区间（HU，亨氏单位）
若.bin raw为设备原始 ADC 采样值，必须先通过RescaleSlope / RescaleIntercept转换为 HU 单位，阈值才具备物理意义。
表格组织结构CT 值 HU 范围特征说明骨小梁（松质骨 Trabecular）150 ~ 850 HU椎体内部网状微细骨质，密度跨度大；骨质疏松时整体 HU 下降骨皮质（密质骨 Cortical）800 ~ 3000 HU骨骼外层致密硬壳，边界锐利；骨折、骨质破坏、骨皮质变薄在此区间识别骨髓（松质骨间隙）-50 ~ 100 HU骨小梁之间低密度区域OpenCV 定向分割阈值
仅提取骨皮质：阈值 ＞ 800 HU
提取全部骨骼（皮质 + 骨小梁）：阈值 ＞ 150 HU
单独分离骨小梁（剔除皮质）：150 ＜ HU ＜ 800
二、观察骨皮质、骨小梁推荐窗宽窗位（WW/WL）窗参数控制可视化对比度，等价于 ImageJ 亮度面板 Min/Max，可直接对接 OpenCV 窗宽窗位线性映射。
计算公式：
\(Min = WL - WW/2\)
\(Max = WL + WW/2\)

通用标准骨窗（兼顾皮质 + 骨小梁・首选）
窗宽 WW = 2000 HU，窗位 WL = 500 HU
显示区间：Min=-500 HU，Max=1500 HU
优势：同时看清高密度骨皮质 + 内部低密度骨小梁网状结构，椎体 CT 常规使用。


窄窗：精细观察骨小梁纹理（骨质疏松筛查）
窗宽 WW = 1500 HU，窗位 WL = 400 HU
显示区间：Min=-350 HU，Max=1150 HU
适用：观察骨小梁稀疏程度、微小骨质改变。


宽窗：重点观察骨皮质完整性（骨折、骨质侵蚀）
窗宽 WW = 2500 HU，窗位 WL = 600 HU
显示区间：Min=-650 HU，Max=1850 HU
适用：观察皮质连续性、骨增生、硬化灶。


实操建议：优先使用【通用标准骨窗】；需要放大骨小梁细节再切换窄窗方案。
三、面向骨小梁 / 骨皮质的锐化算法选型（OpenCV）核心痛点CT 原始图像存在量子噪声；普通锐化会同步放大噪声，造成骨小梁纹理失真。
算法优先级：双边滤波预处理 + USM 非锐化掩膜（首选）＞拉普拉斯保边锐化 ＞简单卷积锐化（不推荐）1、首选算法：USM 非锐化掩膜（Unsharp Mask）最适配骨骼影像，增强微细骨小梁与骨皮质边界。原理\(I_{sharp}=I_{org}+k\cdot(I_{org}-Gauss(I_{org}))\)
k：锐化强度
\(\sigma\)：高斯模糊半径，控制捕捉纹理尺度
骨骼推荐参数（16bit CT 图像）
sigma = 1.2 ~ 2.0
细小骨小梁：1.2；粗骨质纹理：2.0
strength (k) = 0.4 ~ 0.8
禁止超过 1.0，避免边缘光晕伪影
Python 实现（原生支持 16bit）python运行import cv2
import numpy as np

def usm_sharpen_16bit(img_16, sigma=1.5, strength=0.6):
    """
    img_16 : uint16 原始CT图像 CV_16UC1
    return：锐化后uint16图像
    """
    blurred = cv2.GaussianBlur(img_16, ksize=(0,0), sigmaX=sigma)
    sharp = cv2.addWeighted(img_16, 1.0, blurred, -1.0, 0)
    result = cv2.addWeighted(img_16, 1.0, sharp, strength, 0)
    # 截断，防止16位数值溢出
    result = np.clip(result, 0, 65535).astype(np.uint16)
    return result

六、医学影像重要禁忌
严禁先转 8bit 再锐化：必须在 16bit 原始数据完成增强，再执行窗宽映射；否则灰度信息永久丢失。
锐化仅用于可视化观察；骨密度、CT 值定量测量必须使用未经过锐化的原始图像。
禁止过度锐化：强度大于 1.0 易产生人工伪纹理，噪声会被误识别为骨小梁。
