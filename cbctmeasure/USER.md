# CBCT 三维测量与手术规划 — 使用说明

适用页面：**抽屉菜单 → CBCT Measure**（`nav_cbct_measure`）。
本页面在 `:cbctdeal` 已经建好的三维画面上做测量与规划，**不重新加载数据**，所以进入前请先确认已经解析过一次序列（在本页解析也可以，见下）。

> 本页所有数值均由体数据直接计算，**只用于方案设计参考，任何诊断与手术决策必须由临床医师复核**。报告每页页脚都印有这条提示。

---

## 1. 准备：拿到体数据

页面顶部「1) Series Source」三种方式，任选其一：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| 加载 assets/neck_ct | 读内置演示序列（512×512×265，体素 0.7031×0.7031×2.5000 mm） | 快速体验、演示、回归 |
| 选择目录 (SAF) | 系统目录选择器挑一个 DICOM 序列目录 | 自己的数据，路径不确定时 |
| 解析并进入测量 | 解析上方路径里的序列并建会话 | 手输绝对路径后 |

解析完成后「2) Viewport」上方会显示 `解析完成 (xxxx ms)`，同时三维画面出现。
若显示 `(waiting for parse)` 或报错，说明序列目录里没有可读的 DICOM，请先回 CBCT Parse 页确认。

## 2. 画面操作（任何工具下都能用）

| 操作 | 效果 |
|---|---|
| 单指拖动 | VR 模式旋转；测量工具下由该工具接管（不会同时旋转） |
| 双指捏合 / 双指拖动 | 缩放 / 平移 |
| VR 体绘制 · MPR 切面 | 体渲染与三平面切面互切 |
| Axial / Coronal / Sagittal + 位置滑条 | MPR 下切面与层位（`132/264` 是当前层/总层） |
| 窗宽 WW · 窗位 WC | 实时调窗，看骨/软组织不同对比度 |
| 复位相机 | 回到初始视角与初始缩放 |

测量点位的精度依赖画面对比度：**取骨面点之前先把窗宽调到骨骼合适区间**（演示数据可用 CBCT Parse 页的「骨骼窗」量级），否则表面拾取会落在错误的层。

## 3. 测量工具（工具条「3) Measure Tools」）

选一个工具，下方会给出该工具的操作引导文案（`浏览：单指旋转，双指缩放/平移` 那一行）。
**「撤销取点」** 去掉当前草稿的最后一个点；**「丢弃草稿」** 放弃当前这一次未完成的描记；**「清空全部」** 二次确认后清空本页所有条目（不影响磁盘上的归档文件）。

| 工具 | 子类型 | 手势 | 完成条件 |
|---|---|---|---|
| 浏览 | — | 单指旋转 / 双指缩放平移 | 不产生条目 |
| 测距 | 两点距离 / 点到线 / 弧线长度 / HU 采样 / 骨密度 / 牙弓弧线 / 排列角度 / 中线偏移 / 覆合覆盖 | 见下 | 点够点数自动提交 |
| 测角 | — | 依次点 A / **B(顶点)** / C | 三点取完即提交（顶点是第 2 个点） |
| 体积 | — | **按住并拖动**画出一个盒 | 松手即建「ROI 盒」+ 体积测量；每边需 ≥1mm，否则提示「区域太小…已取消」 |
| 面积 | — | 在 MPR 切面上逐笔点出多边形（≥3 点） | **再次点击起点附近（2mm 内）闭合**；点到 120 点会自动闭合 |
| ROI | — | 用「4) ROI / Threshold」面板建阈值/组合 ROI | 面板操作即生效 |
| 种植体 | — | 点击牙槽嵴顶放置入口点 | 点一下就落一颗，随后在结果行里调参数 |
| 神经管 | — | 在当前层逐点描记，切层继续 | 「新建神经管路径并开始描记」建路径，松开进入下一层接着点 |
| 标注 | 文字 / 线段 / 箭头 / 自由曲线 / 环形 / 截面 / 截图圈注 | 文字：点击落点；线段与箭头：点两端；自由曲线：按住拖动；环形：点圆心再拖到边缘；截面：在当前切面点击；截图圈注：点击打圈注（记录像素坐标） | 各自完成后进入结果列表 |

子类型说明（测距条第二行）：

* **弧线长度**：按住沿骨面拖动描记，松手提交（最多 80 个采样点，系统会做深度锁层与中值滤波，避免跳到别的骨面）。
* **HU 采样**：单击取该体素中心原始 HU（不做插值），并给出推断组织名。
* **骨密度**：单击 ROI 内的骨小梁区域，返回均值/标准差/最大/最小 HU。
* **牙弓弧线 / 排列角度 / 中线偏移 / 覆合覆盖**：正畸量。牙弓弧线要在冠状面沿牙弓拖动描记，其余按引导点击对应标志点。

拖动类工具（体积、弧线、自由曲线、环形）**必须按下的那一点就落在有效表面上**：按下点没拾取到，整条轨迹都不会有采样点，表现为「拖了半天没反应」，此时提示区会给出「未拾取到点」之类的原因。

## 4. ROI 与量化（「4) ROI / Threshold」）

| 控件 | 用法 |
|---|---|
| HU 下限 / HU 上限 | 阈值区间，演示数据骨骼可取 200~3000 |
| 建 HU 阈值 ROI | 按当前 HU 区间建 R-01 阈值 ROI（全体积内筛选） |
| 隔离显示 ROI | 只显示当前选中的 ROI，便于看轮廓 |
| 组合 ROI（交/并/差） | 依次弹三次列表选 A / B / C 与两种运算符（`∩` `∪` `−`），生成组合 ROI。子 ROI 必须已存在，否则会提示「缺少子 ROI」而不是给一个错误体积 |

**查看量化结果**：在「5) Results」列表里**点一下 ROI 那一行**，下方摘要区会显示：

```
【ROI #12 量化】
体积 38.124 cm³ | 平均 29.6 HU | 标准差 219.6 | 范围 -997~873
权重体素 30846.0 | 遍历 31556/31556 | 耗时 12 ms
```

* **权重体素**：按角点比例累计的有效体素数（边界体素算部分权重，所以可以是非整数）；
* **遍历 a/b**：实际扫描的体素数 / 包围盒体素数，用来看裁剪是否生效；
* 大盒（百万级体素）单次量化约 20ms，会有一瞬间的等待。

截面（平面）ROI 只统计**你勾画那一层**内的多边形区域，不会把整个半空间算进来。

## 5. 种植体规划与安全判定

1. 选「种植体」工具，在牙槽嵴顶点击放置入口点（可连续放多颗）；
2. 在结果列表点对应行可改 **直径 / 长度 / 俯仰 / 偏转 / 深度**；
3. 神经管必须描记后才会有神经距离读数：选「神经管」→「新建神经管路径并开始描记」→ 逐层点出路径，可设管道半径；
4. 颜色即安全等级（PRD 判据）：
   * **绿色** 安全（骨高 ≥10mm、骨宽 ≥6mm、神经距离 ≥2mm、间距 ≥3mm）
   * **黄色** 临界
   * **红色** 不安全（含神经距离 <2mm）
   未描记神经管时该项显示为「未测量」，不会伪造距离；
5. 任一种植体或神经管的增删改都会触发**整方案重算**，同一条列表里的其它行数值会一起更新。

## 6. 结果列表（「5) Results」）

每行三段信息：`#编号 类型名` / 主数值 / 概要（点名、关联 ROI、备注）。

| 操作 | 效果 |
|---|---|
| 点击行 | 高亮该条目的叠加图形；ROI 行顺带跑一次量化并写入摘要区；神经管行会自动切到描记态并定位该路径；标注行会弹出文本编辑 |
| 显示/隐藏（行右勾） | 单独控制该条目的叠加图形可见性 |
| 删除（行右按钮） | 删除该条目；种植体/神经管删除后方案会重算 |

## 7. 归档与报告（「6) Archive & Report」）

| 按钮 | 结果 |
|---|---|
| 保存归档 | 写 `measurements/`、`annotations/`、`plans/` 三份 JSON（按 StudyUID+SeriesUID 命名），同时留 `.bak` 备份；日志 `saveAll ok=3/3` |
| 恢复归档 | 读回同一一份数据并重建列表、叠加层与安全评估；退出页面或杀掉应用后重新进入，用这个按钮继续上次的工作 |
| 导出报告 (PDF + DICOM SR) | 先弹「报告署名」输入操作者名，点「导出」后依次执行：存三份归档 → 抓当前画面做证据图 → 生成 PDF → 生成 DICOM SR → 读回 SR 自校验；完成后摘要区逐行显示四项结果。**导出前务必把三维画面滚回可见区**，见下方注意事项 |

产物位置（应用专属目录，无需 root）：

```
Android/data/com.example.dcmtkdemo/files/reports/{StudyUID}_{时间戳}.pdf     ← 报告
Android/data/com.example.dcmtkdemo/files/sr/{StudyUID}_{时间戳}.dcm          ← DICOM SR（可 C-STORE 上传 PACS）
files/screenshots/{StudyUID}_{时间戳}.png                                     ← 证据截图
files/{measurements,annotations,plans}/{StudyUID}_{SeriesUID}_*.json         ← 归档
```

报告固定六章：一、患者与数据；二、测量结果（M-01~M-08）；三、兴趣区（R-01~R-05）；四、种植体规划与安全评估（S-01~S-06）；五、人工标注（A-01~A-07）；六、图像证据。内容多时自动分页（A4），条目与画面证据同源，不会「报告里一个数、屏幕上一个数」。

> 导出耗时主要在抓帧（GPU 读回）：真机实测整条链路 `exportAll cost=1381~1432 ms`，期间页面会显示「正在导出报告...」，完成后按钮恢复可用。中途不要退出页面。

> ⚠️ **导出前请把三维画面滚回可见区**。画面被滚出屏幕时渲染线程不再出帧，证据图会抓成**全黑**，而日志仍然打 `evidence=true`（肉眼要在报告的「六、图像证据」里才发现）。真机已复现：画面可见时 PNG 282,849 B / 有效像素 7.13%，画面滚出屏后 PNG 只有 7,760 B / 有效像素 0%。该场景的自动保护（全黑判空并提示）尚未实现，见 `doc/TEST_REPORT.md` §4.4。

## 8. 提示语对照（提示区那一行文字是什么意思）

| 提示 | 原因 | 怎么办 |
|---|---|---|
| `已取 n/2 点`、`已取 n/3 点` | 采点中 | 继续点击 |
| `当前切面未拾取到点` | MPR 下点在切面影像之外 | 往切面图像内部点，或先调窗让目标结构可见 |
| `体积测量需要拖出一个有效区域` | 只点未拖，或按下与抬起都落在空处 | 按住有骨面的位置再拖动 |
| `区域太小（每边需 >= 1.0mm），已取消` | 盒退化 | 拖大一些 |
| `未拾取到点` | 按下点没有命中表面 | 旋转视角后再按下，或调整窗宽窗位 |
| `缺少子 ROI` | 组合 ROI 的 A/B/C 有一个已被删除 | 重新选择存在的子 ROI |
| `待重算` | 输入点不足或体数据变更导致该项无法计算 | 重新取点或恢复对应 ROI |
| `未找到数据字典 dicom.dic，请先在 CBCT Parse 页解析一次序列` | SR 生成需要 DCMTK 字典 | 先去 CBCT Parse 页解析一次再导出 |

## 9. 使用建议与已知限制

* **先 ROI 后测量**：需要骨密度/体积统计时，先建阈值或盒 ROI，再在 ROI 行上取量化，比手工点采样更稳。
* **神经管一定要描记完整**：S-05 的红色警告依赖神经管路径；未描记时相关字段显示未测量而不是 0。
* **切层再描记**：面积/截面标注/神经管都绑定当前 MPR 层，跨层描记请逐层切换，不要靠旋转画面「脑补」深度。
* **双指缩放与描记互斥**：测量态下单指被工具接管，需要调整视角时用双指；本页面没有「长按旋转」之类的隐藏手势。
* **截图证据是二维叠加**：证据图与屏幕所见一致，但不含深度遮挡剔除，密集区域可能出现前后图元叠在一起的情况。
* **AI 自动分割（Phase 2）尚未提供**：所有 ROI 都需要手工设定阈值或勾画。
