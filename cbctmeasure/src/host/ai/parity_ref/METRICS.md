## (a) Architecture / training contract

- Model: `Conv3d(6->8,k3,p1)+Relu+Conv3d(8->8,k3,p1)+Relu+Conv3d(8->2,k3,p1)+Softmax(axis=1)`
- Input `feat` float32 `[1,6,96,96,64]`, output `prob` float32 `[1,2,96,96,64]`, opset 17, 3474 parameters.
- Frozen file: `model/teeth_cnn.onnx`, 14,477 bytes, sha256 `3092730fc2866074…` (full in `device_parity.json`).
- **DEVICE axis order** (authority: `cbctdeal/src/main/cpp/CbctSeriesParser.cpp:436-441` sets
  `vol->width = Columns, vol->height = Rows`, memory layout `[depth][height][width]`;
  `cbctmeasure/src/main/cpp/core/AiEngine.cpp:73` `appDim = {width, height, depth}`;
  `core/AiCore.cpp` indexes `vol[z*sliceSize + y*width + x]`):
  `feat[c][i][j][k]` with i = DICOM column, j = DICOM row, k = z.
  Host canonical arrays (`prep.py`) are (rows, cols, z), so `feat_dev = feat_can.transpose(0,2,1,3)`.
  The model is trained AND exported in device order (3x3x3 kernels are not equivariant under the in-plane swap).
- Training: Adam lr=0.02, betas(0.9,0.999), eps 1e-8, l2 1e-4; 512 patches/epoch (16³, 50 % positive
  centers, pos:neg loss mass 1:4); 2048 updates; 32 epochs run, best epoch 12 (patience 20); seed 20260101.
- Gates recorded in `train2_full.json`: finite-difference gradient check max rel err 8.48e-6 (PASS, <1e-4);
  numpy-vs-ORT on 0101 device features max|diff| 1.25e-6; DICOM re-read feat max|diff| 0.0.

Rules (machine-readable versions in `device_parity.json`):

- **label**: `label[i,j,k]=1 iff double(prob_dev[1,i,j,k]) > 0.49` — strict >, ties→background,
  float32 promoted to double (`AiCore::thresholdMask`). NOT np.argmax: 133 voxels differ from
  argmax (prob[1] ∈ (0.49, 0.5]).
- **inst**: exact `AiCore::connectedComponents` replica — C-order linear scan (i slowest, j, k),
  LIFO stack flood, Neighbor26 table order (a outer / b mid / c inner, skipping 000), drop
  components with RAW flood count < 8, renumber 1..N by descending clipped voxel count (clipping
  via the `redDim` guard; here redDim == modelDim so no clipping occurs). C++ `std::sort` is not
  stable: SIZE TIES EXIST (21, 11, 8 each twice) → for tied sizes only the multiset is guaranteed.
  Census: 34 unique 26-components; the C++ scan itself performs 47 flood starts because erased
  (<8) components are re-seeded behind the scan pointer (replicated exactly; identical kept census
  either way). 24 kept: 4927, 2855, 586, 479, 407, 207, 123, 47, 44, 41, 35, 23, 21, 21, 19, 18,
  13, 12, 11, 11, 10, 9, 8, 8 voxels × 1.728 mm³ — identical multiset to
  `train2_full.json cc_26conn_min8_at_chosen`.
- **hu**: mean raw HU per 2×2×2 app block on the DEVICE-ordered volume (`buildReducedHu`);
  exact because integer HU / 8 is dyadic.
- **gt**: `prep.gt_tooth_at_app_grid` + `prep.downsample_gt_to_red` (canonical) → `transpose(1,0,2)`.
- **centroid/bbox**: `AiGrid::redToWorld` = `((i+0.5)*1.2, (j+0.5)*1.2, (k+0.5)*1.2)` mm (voxel
  CENTER offset per AiTypes.h:130-134, NOT index*spacing); bbox ± half-voxel.
- **PCA**: cov = E[xxᵀ] − mean·meanᵀ from origin moments, Jacobi sweeps ported line-for-line from
  `pcaPrincipalAxis`; compare |axis| up to sign.
- Features gate: transpose identity exact (0.0) and device feat == shipped feat bitwise;
  independent device-order rebuild differs by ≤ 2.98e-8 (1 float32 ulp, 947/3,538,944 elements,
  box-mean channels only) — the addition-order divergence AiCore.cpp:142-149 explicitly documents
  (parity judged by max|diff| + label agreement, not memcmp).
- ORT CPUExecutionProvider determinism: two runs bit-identical (ORT 1.23.2 host; device ORT 1.17,
  same op set).

**Device dump format** (`AiEngine::dumpParity`, core/AiEngine.cpp:143-177, verified):

redDim0, redDim1); then float32 feat, float32 prob, uint8 label, int16 inst.
